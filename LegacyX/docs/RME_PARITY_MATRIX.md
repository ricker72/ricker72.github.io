## Verification loop

For each row: cite the owning RME function, trace the LegacyX consumer, add a focused validator or fixture, build Release, launch `Release-Latest/LegacyXEditor.exe`, capture runtime evidence, then update this matrix. Do not claim full parity while any P0/P1 row remains unresolved.
