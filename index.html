Sobre el proyecto

Qué es LegacyX Editor

Un editor de mapas para servidores OpenTibia (Tibia 10.98) diseñado para mapear, simular y validar contenido con la misma fidelidad que el cliente real.

LegacyX Editor es el sucesor evolutivo de los editores clásicos de mapas OT. Mantiene paridad certificada con Remere's Map Editor (RME) en comportamiento clásico (OTBM, brushes, palettes, ground/wall/doodad, auto-border) y añade una capa de emulación in-game que ningún otro editor ofrece de forma nativa.

Está construido exclusivamente en C# / .NET 10 / Windows Forms. No hay segundo runtime, no hay C++ en producción, no hay IDs inventados. La única autoridad externa de comportamiento clásico es el código fuente de RME (hampusborgos/rme).

El render usa GDI+ y D3D11 / Texture2DArray. El motor de brushes respeta la ruta de transacciones única de RME, garantizando roundtrip OTBM + XML sin romper materiales oficiales.

Arquitectura

El core en el que está basado

Un solo runtime. Una sola autoridad clásica. Una capa de simulación moderna.

RME como autoridad + OTClient como motor de simulación

El comportamiento clásico (brushes, OTBM, items, flags) se valida y replica a partir del código fuente de Remere's Map Editor (commit de referencia da7152e). Las mejoras propietarias nunca rompen OTBM, materiales oficiales ni la ruta de transacciones del Brush Engine. La simulación in-game se apoya en el framework de OTClient (src/client + framework (PlayerWalker, IngameMovementRules, LightView, DAT 10.98 ThingFlagAttr, DrawPool/Shader GLSL→HLSL, etc.), todo reimplementado y embebido en C#.

⚙️

Runtime único

100% C# / .NET 10 / Windows Forms. Sin segundo proceso, sin C++ en producción. Un solo proceso, un solo stack de memoria, máxima controlabilidad.

Brush Engine

Render dual

Diferenciador clave

Ingame Simulation + God Mode

No solo editas el mapa: lo vives desde el editor. Simulación realista del cliente + privilegios de dios para probar, validar y diseñar sin límites.

Ingame Simulation Sim

Emulador in-game basado en el cliente OTClient, embebido dentro del editor. Permite recorrer el mapa con las mismas reglas de movimiento, colisiones, pathfinding y visión de luz que el juego real.

  • Cargar el mapa OTBM y explorarlo como jugador (PlayerWalker / localplayer).
  • Reglas de movimiento reales: BlockObject, PathFind, floor change, elevación.
  • LightView y sistema de iluminación estilo cliente (OTBot / framework).
  • Flags DAT 10.98 (ThingFlagAttr) aplicados en tiempo real.
  • Clock / Timer / EventDispatcher para simular el paso del tiempo y eventos.
  • DrawPool + shaders (GLSL→HLSL) para render coherente con el cliente.
  • Probar teleports, puertas, campos mágicos y cambios de floor sin servidor.
  • Validar spawns, densidades y flow de zonas antes de subir el mapa.
  • Camera picking con offset de floor para pintar y seleccionar en plantas bajas.
  • Certificado desde v1.8.1 — estado 🟢 Certified.

God Mode GOD

Capa de privilegios sobre la simulación: atraviesa obstáculos, salta floors, inspecciona y manipula el entorno sin las restricciones del jugador normal. Accesible desde el menú Ingame Simulation / View (Ctrl+G reservado a Go To Position, paridad RME).

  • Activar / desactivar God Mode desde menú (sin romper atajos clásicos de RME).
  • Moverse libremente ignorando bloqueos de path y unpassable (estilo noclip controlado).
  • Ir a cualquier posición (Go To Position) y saltar entre floors al instante.
  • Inspeccionar items, flags y propiedades bajo el cursor en tiempo real.
  • Probar comportamientos de items (doors, teleports, magic fields) sin morir ni quedar atrapado.
  • Combinar con Live Collaboration para revisar mapas en equipo con visión “dios”.
  • Útil para QA de mapas, balance de hunts y diseño de dungeons complejos.
  • Integrado en el mismo runtime C# — sin cliente externo ni servidor de prueba.
  • Theming oscuro completo: diálogos, paneles y menús consistentes.
  • Parte del stack evolucionado: Sim + GOD + Planner + Collaboration.
